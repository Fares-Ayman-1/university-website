## What the OS does for you

<Ar>ما الذي يفعله نظام التشغيل من أجلك</Ar>

An operating system **manages the system's resources**: the **disk** (files), **input devices** (keyboard, mouse), **output devices** (screen, printer) and **software processes** (running programs). It sits between you, your programs and the hardware, as covered in Lecture 1.

<Ar>يتولّى نظام التشغيل **إدارة موارد النظام (system resources)**: **القرص (disk)** (الملفات)، و**أجهزة الإدخال (input devices)** (لوحة المفاتيح والفأرة)، و**أجهزة الإخراج (output devices)** (الشاشة والطابعة)، و**العمليات البرمجية (software processes)** (البرامج قيد التشغيل). وهو يقع بينك وبين برامجك والعتاد (hardware)، كما شرحنا في المحاضرة 1.</Ar>

<SlideFigure page={3} caption="The OS manages the CPU, RAM, disk, input and output devices, and software processes." captionAr="يدير نظام التشغيل المعالج (CPU) والذاكرة (RAM) والقرص وأجهزة الإدخال والإخراج والعمليات البرمجية." />

| Interface <Ar>الواجهة</Ar> | You interact by… <Ar>تتفاعل عن طريق…</Ar> | Strengths <Ar>نقاط القوة</Ar> |
|---|---|---|
| **GUI**: graphical user interface <Ar>**GUI**: الواجهة الرسومية للمستخدم</Ar> | Clicking icons, windows and menus <Ar>النقر على الأيقونات والنوافذ والقوائم</Ar> | Easy to learn and discover <Ar>سهلة التعلّم والاستكشاف</Ar> |
| **CLI**: command-line interface <Ar>**CLI**: واجهة سطر الأوامر</Ar> | Typing commands <Ar>كتابة الأوامر</Ar> | Fast, precise, **scriptable**, and works over remote connections with few resources <Ar>سريعة ودقيقة و**قابلة للأتمتة بالسكربتات (scriptable)**، وتعمل عبر الاتصالات البعيدة بموارد قليلة</Ar> |

Desktop OSes include Windows, macOS and Linux distributions. Mobile OSes include Android (built on the Linux kernel) and iOS.

<Ar>من أنظمة تشغيل الحواسيب المكتبية (Desktop) ويندوز (Windows) و macOS وتوزيعات لينكس، ومن أنظمة تشغيل الهواتف المحمولة أندرويد (Android) (المبني على نواة لينكس) و iOS.</Ar>

## Terminal, shell and kernel

<Ar>الطرفية والصدفة والنواة</Ar>

<Steps>

1. The **terminal** is the window (an application) that accepts what you type and displays output. Open one in Ubuntu with **Ctrl + Alt + T**.
   <Ar>**الطرفية (terminal)** هي النافذة (وهي تطبيق) التي تستقبل ما تكتبه وتعرض المخرجات. افتح واحدة في Ubuntu باستخدام **Ctrl + Alt + T**.</Ar>
2. The **shell** **interprets** your command and asks the OS to run it. Ubuntu's default shell is **Bash** (Bourne-Again SHell).
   <Ar>**الصدفة (shell)** **تفسّر** أمرك وتطلب من نظام التشغيل تنفيذه. والصدفة الافتراضية في Ubuntu هي **Bash** (Bourne-Again SHell).</Ar>
3. The **kernel** is the core of the OS. It communicates **directly with the hardware** and carries out the request through system calls.
   <Ar>**النواة (kernel)** هي لبّ نظام التشغيل، فهي تتواصل **مباشرةً مع العتاد (hardware)** وتنفّذ الطلب عبر استدعاءات النظام (system calls).</Ar>
4. The **hardware** does the actual work.
   <Ar>**العتاد (hardware)** هو الذي يؤدي العمل الفعلي.</Ar>

</Steps>

<SlideFigure page={7} caption="The terminal passes your command to the shell, which runs it through the kernel on the hardware." captionAr="تمرّر الطرفية أمرك إلى الصدفة، التي تنفّذه عبر النواة على العتاد." />

```bash title="Terminal"
echo $SHELL      # /bin/bash  — which shell you are using
uname -s         # Linux      — the kernel name
uname -r         # e.g. 6.8.0-45-generic — the kernel release
```

## Linux distributions

<Ar>توزيعات لينكس</Ar>

The **Linux kernel** alone isn't a complete OS. A **distribution** packages the kernel with the GNU tools, a package manager, a desktop and applications.

<Ar>**نواة لينكس (Linux kernel)** وحدها ليست نظام تشغيل كاملًا. أما **التوزيعة (distribution)** فتجمع النواة مع أدوات GNU ومدير الحزم (package manager) وسطح مكتب وتطبيقات.</Ar>

| Family <Ar>العائلة</Ar> | Distributions <Ar>التوزيعات</Ar> | Package manager <Ar>مدير الحزم</Ar> |
|---|---|---|
| Debian <Ar>ديبيان (Debian)</Ar> | **Ubuntu**, Debian, Linux Mint, Kali <Ar>**أوبونتو (Ubuntu)**، وديبيان (Debian)، ولينكس منت (Linux Mint)، وكالي (Kali)</Ar> | `apt` (`.deb`) |
| Red Hat <Ar>ريد هات (Red Hat)</Ar> | Fedora, RHEL, CentOS Stream, Rocky <Ar>فيدورا (Fedora)، و RHEL، و CentOS Stream، وروكي (Rocky)</Ar> | `dnf` / `yum` (`.rpm`) |
| Others <Ar>أخرى</Ar> | Arch, openSUSE, Alpine <Ar>آرك (Arch)، و openSUSE، وألباين (Alpine)</Ar> | `pacman`, `zypper`, `apk` |

The labs use **Ubuntu**.

<Ar>تستخدم المعامل توزيعة **Ubuntu**.</Ar>

## Getting Ubuntu for the labs

<Ar>الحصول على Ubuntu للمعامل</Ar>

<Grid cols={2}>
  <Card title="Option A: WSL (Windows)" titleAr="الخيار أ: WSL (Windows)" tag="quickest">
    The Windows Subsystem for Linux runs a real Ubuntu inside Windows. Open PowerShell <strong>as administrator</strong>, run <code>wsl --install</code>, reboot, then open <strong>Ubuntu</strong> from the Start menu and create a user name and password.

    <Ar>يشغّل نظام ويندوز الفرعي للينكس (Windows Subsystem for Linux) نسخة Ubuntu حقيقية داخل ويندوز. افتح PowerShell <strong>بصلاحيات مدير النظام (administrator)</strong>، ونفّذ <code>wsl --install</code>، وأعد تشغيل الجهاز، ثم افتح <strong>Ubuntu</strong> من قائمة ابدأ (Start) وأنشئ اسم مستخدم وكلمة مرور.</Ar>
  </Card>
  <Card title="Option B: a VirtualBox VM" titleAr="الخيار ب: آلة افتراضية على VirtualBox" tag="full desktop">
    A complete Ubuntu desktop in a window, isolated from your main system. It is closest to the lab machines.

    <Ar>سطح مكتب Ubuntu كامل داخل نافذة، معزول عن نظامك الأساسي، وهو الأقرب إلى أجهزة المعمل.</Ar>
  </Card>
</Grid>

The steps for **Option B** from the slides:

<Ar>خطوات **الخيار ب** كما في الشرائح:</Ar>

<Steps>

1. **Enable virtualization** (Intel VT-x / AMD-V) in your BIOS/UEFI settings.
   <Ar>**فعّل المحاكاة الافتراضية (virtualization)** (Intel VT-x / AMD-V) من إعدادات BIOS/UEFI.</Ar>
2. **Install the prerequisites** VirtualBox asks for. The slides mention the JDK; current VirtualBox versions may also need the Microsoft Visual C++ redistributable.
   <Ar>**ثبّت المتطلبات المسبقة (prerequisites)** التي يطلبها VirtualBox. تذكر الشرائح حزمة JDK، وقد تحتاج الإصدارات الحالية من VirtualBox أيضًا إلى حزمة Microsoft Visual C++ redistributable.</Ar>
3. **Install VirtualBox**.
   <Ar>**ثبّت VirtualBox**.</Ar>
4. **Create a virtual machine**: Linux / Ubuntu (64-bit), at least 4 GB RAM, 2 CPUs and a 25 GB disk.
   <Ar>**أنشئ آلة افتراضية (virtual machine)**: Linux / Ubuntu (64-bit)، بذاكرة RAM لا تقل عن 4 GB، ومعالجين (2 CPUs)، وقرص بسعة 25 GB.</Ar>
5. **Install Ubuntu** in the VM from the Ubuntu Desktop ISO.
   <Ar>**ثبّت Ubuntu** على الآلة الافتراضية من ملف Ubuntu Desktop ISO.</Ar>

</Steps>

```powershell title="PowerShell (admin) — Option A"
wsl --install            # installs WSL and Ubuntu
wsl -l -v                # list installed distributions and their WSL version
```

<Takeaways>

- The OS manages **disks, devices and processes**; you reach it through a **GUI** or a **CLI**.
  <Ar>يدير نظام التشغيل **الأقراص والأجهزة والعمليات (processes)**، وتصل إليه عبر **واجهة رسومية (GUI)** أو **سطر أوامر (CLI)**.</Ar>
- **Terminal** (the window) → **shell** (Bash, the interpreter) → **kernel** (talks to the hardware).
  <Ar>**الطرفية (terminal)** (النافذة) ← **الصدفة (shell)** (Bash، المفسِّر) ← **النواة (kernel)** (تتخاطب مع العتاد).</Ar>
- A **distribution** = Linux kernel + tools + package manager. The labs use **Ubuntu**.
  <Ar>**التوزيعة (distribution)** = نواة لينكس + أدوات + مدير حزم. وتستخدم المعامل **Ubuntu**.</Ar>
- Get Ubuntu through **WSL** (`wsl --install`) or a **VirtualBox** VM, and follow NDG Linux Essentials from Module 5.
  <Ar>احصل على Ubuntu عبر **WSL** (`wsl --install`) أو آلة افتراضية على **VirtualBox**، واتبع مقرر NDG Linux Essentials بدءًا من الوحدة 5.</Ar>

</Takeaways>
