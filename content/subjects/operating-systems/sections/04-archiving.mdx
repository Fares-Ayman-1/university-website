- Compress and decompress single files with **gzip**, **bzip2** and **xz**.

  <Ar>استخدام **tar** بأوضاعه الثلاثة (**الإنشاء** و**العرض** و**الاستخراج**)، مع الضغط ودونه، و**الإلحاق (append)** بأرشيف.</Ar>

## Why archive and compress?

<Ar>لماذا نؤرشف ونضغط؟</Ar>

- **Transfer**: smaller files move faster.
  <Ar>**النقل**: الملفات الأصغر تنتقل أسرع.</Ar>
- **Convenience**: one bundle is easier to send than hundreds of files.
  <Ar>**السهولة**: إرسال حزمة واحدة أسهل من إرسال مئات الملفات.</Ar>
- **Space**: archives and compressed files take less room, which matters on USB drives.
  <Ar>**المساحة**: الأرشيفات والملفات المضغوطة تشغل مساحة أقل، وهذا مهم في وحدات تخزين USB.</Ar>

| Operation <Ar>العملية</Ar> | Does <Ar>ماذا تفعل</Ar> | Tools <Ar>الأدوات</Ar> |
|---|---|---|
| **Compression** <Ar>**الضغط (Compression)**</Ar> | Makes **one** file smaller <Ar>تصغّر حجم ملف **واحد**</Ar> | `gzip`, `bzip2`, `xz` |
| **Archiving** <Ar>**الأرشفة (Archiving)**</Ar> | Combines **many** files and directories into **one** file <Ar>تجمع ملفات ومجلدات **كثيرة** في ملف **واحد**</Ar> | `tar` |
| **Both** <Ar>**كلاهما**</Ar> | Bundles and compresses in one go <Ar>تجمع وتضغط في خطوة واحدة</Ar> | `tar -z/-j/-J`, `zip` |

Compression is **lossless**: decompressing gives back the exact original. Text compresses very well, while already-compressed media (JPEG, MP4) barely shrinks.

<Ar>الضغط هنا **بلا فقدان (lossless)**: فك الضغط يعيد الأصل كما هو تمامًا. النصوص تنضغط جيدًا جدًا، بينما الوسائط المضغوطة أصلًا (JPEG و MP4) بالكاد يصغر حجمها.</Ar>

## gzip and bzip2

<Ar>الأداتان gzip و bzip2</Ar>

```bash title="Terminal"
cp /usr/share/dict/words .      # a large text file to practise on
ls -l words                     # note the size

gzip words                      # replaces words with words.gz (much smaller)
ls -l words.gz
gunzip words.gz                 # restores words and removes words.gz

bzip2 words                     # → words.bz2 (usually smaller than .gz, but slower)
bunzip2 words.bz2               # → words
```

| Tool <Ar>الأداة</Ar> | Extension <Ar>الامتداد</Ar> | Compress <Ar>الضغط</Ar> | Decompress <Ar>فك الضغط</Ar> | Character <Ar>الخصائص</Ar> |
|---|---|---|---|---|
| **gzip** <Ar>الأداة **gzip**</Ar> | `.gz` | `gzip file` | `gunzip file.gz` | Fast and universal <Ar>سريعة ومنتشرة في كل مكان</Ar> |
| **bzip2** <Ar>الأداة **bzip2**</Ar> | `.bz2` | `bzip2 file` | `bunzip2 file.bz2` | Better ratio, slower <Ar>نسبة ضغط أفضل، لكنها أبطأ</Ar> |
| **xz** <Ar>الأداة **xz**</Ar> | `.xz` | `xz file` | `unxz file.xz` | Best ratio, slowest to compress <Ar>أفضل نسبة ضغط، والأبطأ في الضغط</Ar> |

Useful options: `-k` keeps the original file, `-v` shows the compression ratio, `-l` (gzip) lists sizes, and `-c` writes to standard output.

<Ar>خيارات مفيدة: `-k` يُبقي الملف الأصلي، و `-v` يعرض نسبة الضغط، و `-l` (في gzip) يعرض الأحجام، و `-c` يكتب إلى المخرج القياسي (standard output).</Ar>

## tar: tape archive

<Ar>الأمر tar: أرشيف الشريط (tape archive)</Ar>

`tar` bundles files and directories, preserving the directory structure, permissions and timestamps, into one **tarball**. It has **three modes**:

<Ar>يجمع `tar` الملفات والمجلدات في ملف واحد يُسمّى **tarball**، مع الحفاظ على بنية المجلدات والصلاحيات (permissions) والطوابع الزمنية (timestamps). وله **ثلاثة أوضاع**:</Ar>

| Mode <Ar>الوضع</Ar> | Option <Ar>الخيار</Ar> | Does <Ar>الوظيفة</Ar> |
|---|---|---|
| **Create** <Ar>**الإنشاء**</Ar> | `-c` | Make a new archive <Ar>إنشاء أرشيف جديد</Ar> |
| **List** (table) <Ar>**العرض** (جدول المحتويات)</Ar> | `-t` | Show the contents without extracting <Ar>عرض المحتويات دون استخراجها</Ar> |
| **Extract** <Ar>**الاستخراج**</Ar> | `-x` | Pull files out of the archive <Ar>إخراج الملفات من الأرشيف</Ar> |

Add these options to a mode:

<Ar>أضف هذه الخيارات إلى الوضع:</Ar>

| Option <Ar>الخيار</Ar> | Meaning <Ar>المعنى</Ar> |
|---|---|
| `-f FILE` | The archive **file** name (almost always needed; put it last in the group) <Ar>اسم **ملف** الأرشيف (مطلوب في أغلب الأحيان، وضعه آخر الخيارات في المجموعة)</Ar> |
| `-v` | **Verbose**: list each file as it is processed <Ar>**التفصيل (Verbose)**: عرض كل ملف أثناء معالجته</Ar> |
| `-z` | Compress or decompress with **gzip** (`.tar.gz` / `.tgz`) <Ar>الضغط أو فك الضغط باستخدام **gzip** (`.tar.gz` / `.tgz`)</Ar> |
| `-j` | Compress or decompress with **bzip2** (`.tar.bz2`) <Ar>الضغط أو فك الضغط باستخدام **bzip2** (`.tar.bz2`)</Ar> |
| `-J` | Compress or decompress with **xz** (`.tar.xz`) <Ar>الضغط أو فك الضغط باستخدام **xz** (`.tar.xz`)</Ar> |
| `-r` | **Append** files to an existing (uncompressed) archive <Ar>**إلحاق** ملفات بأرشيف موجود (غير مضغوط)</Ar> |
| `-C DIR` | Change to DIR before extracting <Ar>الانتقال إلى المجلد `DIR` قبل الاستخراج</Ar> |

```bash title="Terminal"
mkdir -p ~/mybackups
tar -cvf ~/mybackups/udev.tar /etc/udev       # create (verbose) an uncompressed archive
tar -tvf ~/mybackups/udev.tar                 # list its contents
tar -zcvf ~/mybackups/udev.tar.gz /etc/udev   # create a gzip-compressed archive
tar -jcvf ~/mybackups/udev.tar.bz2 /etc/udev  # …bzip2-compressed
tar -xvf ~/mybackups/udev.tar                 # extract into the current directory
tar -zxvf udev.tar.gz -C /tmp/restore         # extract a .tar.gz into /tmp/restore
tar -rvf ~/mybackups/udev.tar /etc/hosts      # append a file (uncompressed archives only)
tar -tf ~/mybackups/udev.tar | grep hosts     # verify that it was added
```

<Callout type="note" title="The leading slash" titleAr="الشرطة المائلة في بداية المسار">
  When you archive `/etc/udev`, tar prints <em>"Removing leading '/' from member names"</em> and stores <code>etc/udev/…</code>. Extracting then recreates <code>etc/udev</code> <strong>under the current directory</strong>, so a restore can't accidentally overwrite the real system files.

  <Ar>عندما تؤرشف `/etc/udev`، يطبع tar الرسالة <em>«Removing leading '/' from member names»</em> ويخزّن <code>etc/udev/…</code>. وعند الاستخراج يُعاد إنشاء <code>etc/udev</code> <strong>تحت المجلد الحالي</strong>، فلا يمكن لعملية الاستعادة أن تستبدل ملفات النظام الحقيقية عن طريق الخطأ.</Ar>
</Callout>

<Callout type="tip" title="How to remember tar" titleAr="كيف تتذكر خيارات tar">
  <strong>c</strong>reate / e<strong>x</strong>tract / lis<strong>t</strong> + <strong>v</strong>erbose + <strong>f</strong>ile, with <strong>z</strong> for gzip. "<code>tar -czvf</code>: create zipped verbose file." "<code>tar -xzvf</code>: extract zipped verbose file."

  <Ar><strong>c</strong> للإنشاء (create) / <strong>x</strong> للاستخراج (extract) / <strong>t</strong> للعرض (list) + <strong>v</strong> للتفصيل (verbose) + <strong>f</strong> للملف (file)، مع <strong>z</strong> لـ gzip. «<code>tar -czvf</code>: أنشئ (create) ملفًا (file) مضغوطًا (zipped) مع التفصيل (verbose)». «<code>tar -xzvf</code>: استخرج (extract) ملفًا مضغوطًا مع التفصيل».</Ar>
</Callout>

## zip and unzip

<Ar>الأداتان zip و unzip</Ar>

`zip` archives **and** compresses at once, and is the standard on Windows, so it is the best choice for sharing with non-Linux users.

<Ar>يؤرشف `zip` **و**يضغط في آنٍ واحد، وهو المعيار في ويندوز (Windows)، ولذلك فهو الخيار الأفضل للمشاركة مع مستخدمي الأنظمة غير لينكس.</Ar>

```bash title="Terminal"
zip words.zip words                    # compress a single file
zip -r udev.zip /etc/udev              # -r: include a directory and its contents
unzip -l udev.zip                      # list the contents
rm -r etc                              # (clean up the files from the tar example)
unzip udev.zip                         # extract into the current directory
unzip udev.zip -d /tmp/out             # extract into another directory
```

| | tar.gz / tar.bz2 / tar.xz <Ar>أرشيفات `tar.gz` / `tar.bz2` / `tar.xz`</Ar> | zip <Ar>أرشيفات `zip`</Ar> |
|---|---|---|
| Typical platform <Ar>المنصة المعتادة</Ar> | Linux and UNIX <Ar>لينكس و UNIX</Ar> | Windows and everywhere <Ar>ويندوز وكل مكان</Ar> |
| Compression <Ar>الضغط</Ar> | The whole archive as one stream (better ratio) <Ar>الأرشيف كله كتدفق (stream) واحد (نسبة ضغط أفضل)</Ar> | Each file separately (fast random access) <Ar>كل ملف على حدة (وصول عشوائي سريع)</Ar> |
| Permissions and ownership <Ar>الصلاحيات والملكية</Ar> | Fully preserved <Ar>محفوظة بالكامل</Ar> | Limited <Ar>محدودة</Ar> |

<Takeaways>

- **Compression** shrinks one file (`gzip`, `bzip2`, `xz`); **archiving** bundles many (`tar`).
  <Ar>**الضغط (Compression)** يصغّر ملفًا واحدًا (`gzip` و `bzip2` و `xz`)، و**الأرشفة (archiving)** تجمع ملفات كثيرة (`tar`).</Ar>
- `gzip`/`gunzip` (`.gz`) are fast; `bzip2`/`bunzip2` (`.bz2`) and `xz` (`.xz`) compress better and more slowly. All of them replace the original unless you use `-k`.
  <Ar>`gzip`/`gunzip` (`.gz`) سريعان، أما `bzip2`/`bunzip2` (`.bz2`) و `xz` (`.xz`) فتضغط بشكل أفضل لكن أبطأ. وجميعها تستبدل الملف الأصلي ما لم تستخدم `-k`.</Ar>
- `tar` modes are **c**reate, **t** (list) and e**x**tract; `-f` names the file, `-v` is verbose, and `-z`/`-j`/`-J` add compression.
  <Ar>أوضاع `tar` هي الإنشاء **c** (create)، والعرض **t** (list)، والاستخراج **x** (extract)؛ و `-f` يحدد اسم الملف، و `-v` للتفصيل (verbose)، و `-z`/`-j`/`-J` تضيف الضغط.</Ar>
- `zip -r` and `unzip` (`-l` to list, `-d` to choose the target) are the cross-platform option.
  <Ar>`zip -r` و `unzip` (`-l` للعرض، و `-d` لاختيار المجلد الهدف) هما الخيار المتوافق مع مختلف الأنظمة (cross-platform).</Ar>

</Takeaways>

## Practice

<Ar>تدريب</Ar>

<Exercise title="Back up your labs" titleAr="انسخ معاملك احتياطيًا" level="easy">

Create a gzip-compressed archive `labs.tar.gz` of the `~/projects` directory, then list its contents without extracting.

<Ar>أنشئ أرشيفًا مضغوطًا بـ gzip باسم `labs.tar.gz` للمجلد `~/projects`، ثم اعرض محتوياته دون استخراجها.</Ar>

<Solution>

```bash
tar -czvf labs.tar.gz ~/projects
tar -tzvf labs.tar.gz      # -z is optional when listing with modern GNU tar
```

</Solution>

</Exercise>

<Exercise title="Restore somewhere safe" titleAr="الاستعادة في مكان آمن" level="medium">

Extract only the contents of `labs.tar.gz` into `/tmp/check` to inspect them, without touching your real files.

<Ar>استخرج محتويات `labs.tar.gz` فقط إلى `/tmp/check` لفحصها، دون المساس بملفاتك الحقيقية.</Ar>

<Solution>

```bash
mkdir -p /tmp/check
tar -xzvf labs.tar.gz -C /tmp/check
ls -R /tmp/check
```

</Solution>

</Exercise>

<Exercise title="Which tool?" titleAr="أي أداة؟" level="easy">

You need to email a folder of reports to a colleague on Windows. Which command do you use?

<Ar>تحتاج إلى إرسال مجلد من التقارير بالبريد الإلكتروني إلى زميل يستخدم ويندوز (Windows). أي أمر تستخدم؟</Ar>

<Solution>

`zip -r reports.zip reports/`. Windows opens `.zip` files natively, while a `.tar.gz` needs extra software.

<Ar>`zip -r reports.zip reports/`. يفتح ويندوز ملفات `.zip` بشكل مدمج (natively)، بينما يحتاج ملف `.tar.gz` إلى برنامج إضافي.</Ar>

</Solution>

</Exercise>
