## Files, directories and paths

<Ar>الملفات والمجلدات والمسارات</Ar>

On Linux, data is stored in **files**, and files are organized in **directories** (folders). A directory is itself a special file that stores the **names** of its entries and their **inode numbers**, the unique IDs that point to each file's data on disk.

<Ar>في لينكس (Linux) تُخزَّن البيانات في **ملفات**، وتُنظَّم الملفات في **مجلدات (directories)**. والمجلد نفسه ملف خاص يخزّن **أسماء** العناصر التي يحتويها و**أرقام العقد الفهرسية (inode numbers)** الخاصة بها، وهي معرّفات فريدة تشير إلى بيانات كل ملف على القرص.</Ar>

- **Names are case-sensitive**: `Notes.txt` and `notes.txt` are different files.
  <Ar>**الأسماء حسّاسة لحالة الأحرف (case-sensitive)**: `Notes.txt` و `notes.txt` ملفان مختلفان.</Ar>
- Everything hangs from a single **root directory** `/`, with no drive letters.
  <Ar>كل شيء يتفرّع من **مجلد جذر (root directory)** واحد هو `/`، دون أحرف للأقراص (drive letters).</Ar>
- Your **home directory** is `/home/<user>`, shortened to **`~`**. New terminals start there.
  <Ar>**مجلدك الرئيسي (home directory)** هو `/home/<user>`، ويُختصر إلى **`~`**، ومنه تبدأ الطرفيات الجديدة.</Ar>

| Path type <Ar>نوع المسار</Ar> | Starts from <Ar>يبدأ من</Ar> | Example <Ar>مثال</Ar> |
|---|---|---|
| **Absolute** <Ar>**مطلق**</Ar> | The root `/`; works from anywhere <Ar>الجذر `/`، ويعمل من أي مكان</Ar> | `/home/sysadmin/Documents` |
| **Relative** <Ar>**نسبي**</Ar> | The **current** directory <Ar>المجلد **الحالي**</Ar> | `Documents`, `../Public`, `./script.sh` |

| Symbol <Ar>الرمز</Ar> | Means <Ar>المعنى</Ar> |
|---|---|
| `.` | The current directory <Ar>المجلد الحالي</Ar> |
| `..` | The parent directory <Ar>المجلد الأب</Ar> |
| `~` | Your home directory <Ar>مجلدك الرئيسي</Ar> |
| `-` (with cd) <Ar>`-` (مع `cd`)</Ar> | The previous directory <Ar>المجلد السابق</Ar> |

```bash title="Terminal"
pwd                    # /home/sysadmin
cd /etc/sound          # absolute path
pwd                    # /etc/sound
cd ..                  # up one level  → /etc
cd ../home/sysadmin    # relative path → /home/sysadmin
cd Documents           # relative      → /home/sysadmin/Documents
cd -                   # back to the previous directory
cd                     # no argument   → home (same as cd ~)
```

## Listing with ls

<Ar>عرض المحتويات باستخدام ls</Ar>

```bash title="Terminal"
ls                     # names in the current directory (colors show the type)
ls -a                  # all, including hidden files (names starting with ".")
ls -l                  # long format: permissions, links, owner, group, size, date, name
ls -lh                 # sizes in K/M/G
ls -lt                 # newest first
ls -R /etc/udev        # recursive: also list every subdirectory (careful with big trees!)
```

Hidden files such as **`.bashrc`**, the Bash configuration, begin with a dot.

<Ar>الملفات المخفية (hidden files) مثل **`.bashrc`**، وهو ملف إعدادات Bash، تبدأ أسماؤها بنقطة.</Ar>

```text title="ls -l output"
-rw-r--r-- 1 sysadmin sysadmin  647 Oct 21 14:02 notes.txt
drwxr-xr-x 2 sysadmin sysadmin 4096 Oct 21 13:55 Documents
│└───┬───┘ │ └──┬───┘ └──┬───┘  │   └────┬─────┘ └─ name
│   perms links owner   group  size   modified
└─ type: - file, d directory, l symbolic link
```

### Globs with ls: use -d

<Ar>أنماط التوسيع مع ls: استخدم `-d`</Ar>

When a glob matches a **directory**, plain `ls` lists that directory's **contents**. Add **`-d`** to list the matching names themselves:

<Ar>عندما يطابق نمط التوسيع (glob) **مجلدًا**، يعرض `ls` العادي **محتويات** ذلك المجلد. أضف **`-d`** لعرض الأسماء المطابقة نفسها:</Ar>

```bash title="Terminal"
ls /etc/s*             # shows the contents of matching directories too, which is confusing
ls -d /etc/s*          # just the matching names
```

## Copying with cp

<Ar>النسخ باستخدام cp</Ar>

```text
cp [OPTION] SOURCE DESTINATION
```

```bash title="Terminal"
cp /etc/hosts ~                    # copy into your home directory
cp -v /etc/hosts .                 # . = here; -v (verbose) reports what it did
# '/etc/hosts' -> './hosts'
cp -p /etc/hosts ~                 # preserve timestamps, mode and ownership
cp /etc/hosts ~/hosts.bak          # copy under a different name
cp -R /etc/udev ~/udev-copy        # -R / -r: copy a directory and everything in it
cp -i notes.txt Documents/         # -i: ask before overwriting
```

<Callout type="warning" title="cp overwrites silently" titleAr="الأمر cp يستبدل الملفات بصمت">
  If the destination file exists, `cp` replaces it without asking. Use `-i` (interactive) or `-n` (never overwrite) when that matters.

  <Ar>إذا كان الملف الهدف موجودًا، يستبدله `cp` دون أن يسأل. استخدم `-i` (تفاعلي) أو `-n` (عدم الاستبدال أبدًا) عندما يكون ذلك مهمًا.</Ar>
</Callout>

## Moving and renaming with mv

<Ar>النقل وإعادة التسمية باستخدام mv</Ar>

Moving is like **cut and paste**: the file is removed from the source and appears at the destination. Within one filesystem it is instant, because only the directory entry changes. **Renaming** is just a move within the same directory.

<Ar>النقل يشبه **القص واللصق**: يُزال الملف من المصدر ويظهر في الوجهة. وهو فوري داخل نظام الملفات (filesystem) الواحد، لأن ما يتغير هو مُدخل المجلد (directory entry) فقط. أما **إعادة التسمية** فهي مجرد نقل داخل المجلد نفسه.</Ar>

```bash title="Terminal"
mv hosts Documents/             # move into a directory
mv Documents/hosts myhosts      # move back and rename in one step
mv notes.txt todo.md Public/    # several files into one directory
mv old_dir new_dir              # rename a directory (no -r needed)
```

## Creating and deleting

<Ar>الإنشاء والحذف</Ar>

```bash title="Terminal"
mkdir projects                  # make a directory
mkdir -p projects/os/lab3       # -p: create missing parents, no error if it exists
touch projects/os/lab3/a.txt    # create an empty file (or update its timestamp)

rm a.txt                        # delete a file (there is NO recycle bin)
rm -i *.txt                     # ask before each deletion
rmdir empty_dir                 # delete a directory only if it is EMPTY
rm -r projects                  # delete a directory and everything inside it, recursively
```

<Callout type="warning" title="rm is permanent" titleAr="الحذف باستخدام rm نهائي">
  Deleted files don't go to a trash bin. Check globs first with <code>echo</code> or <code>ls</code> (for example <code>ls *.log</code> before <code>rm *.log</code>), and never run <code>rm -rf</code> on a path you haven't double-checked.

  <Ar>الملفات المحذوفة لا تذهب إلى سلة المهملات. تحقّق من أنماط التوسيع (globs) أولًا باستخدام <code>echo</code> أو <code>ls</code> (مثلًا <code>ls *.log</code> قبل <code>rm *.log</code>)، ولا تشغّل أبدًا <code>rm -rf</code> على مسار لم تتحقق منه جيدًا.</Ar>
</Callout>

<Takeaways>

- One tree from `/`. Absolute paths start at `/`; relative paths start at the current directory (`.`, `..`, `~`).
  <Ar>شجرة واحدة تبدأ من `/`. المسارات المطلقة تبدأ من `/`، والمسارات النسبية تبدأ من المجلد الحالي (`.` و `..` و `~`).</Ar>
- `pwd` shows where you are; `cd`, `cd ..`, `cd ~` and `cd -` move you around.
  <Ar>`pwd` يعرض مكانك، و `cd` و `cd ..` و `cd ~` و `cd -` تنقلك بين المجلدات.</Ar>
- `ls -a` shows hidden files, `-l` details, `-R` recursion, `-d` the names that globs match.
  <Ar>`ls -a` يعرض الملفات المخفية، و `-l` التفاصيل، و `-R` العرض التعاودي (recursion)، و `-d` الأسماء التي تطابقها أنماط التوسيع.</Ar>
- `cp` copies (`-v` verbose, `-p` preserve, `-R` directories), `mv` moves and renames, `mkdir -p` builds trees.
  <Ar>`cp` ينسخ (`-v` لعرض التفاصيل، و `-p` للحفاظ على الخصائص، و `-R` للمجلدات)، و `mv` ينقل ويعيد التسمية، و `mkdir -p` يبني أشجار المجلدات.</Ar>
- `rm` deletes permanently, `rmdir` removes only empty directories, and `rm -r` removes whole trees.
  <Ar>`rm` يحذف نهائيًا، و `rmdir` يزيل المجلدات الفارغة فقط، و `rm -r` يزيل أشجارًا كاملة.</Ar>

</Takeaways>

<Exercise title="Paths" titleAr="المسارات" level="easy">

You are in `/home/sysadmin/Documents`. Give a relative and an absolute command to change to `/home/sysadmin/Public`.

<Ar>أنت في `/home/sysadmin/Documents`. اكتب أمرًا بمسار نسبي وآخر بمسار مطلق للانتقال إلى `/home/sysadmin/Public`.</Ar>

<Solution>

Relative: `cd ../Public`. Absolute: `cd /home/sysadmin/Public`, or `cd ~/Public`.

<Ar>النسبي: `cd ../Public`. المطلق: `cd /home/sysadmin/Public`، أو `cd ~/Public`.</Ar>

</Solution>

</Exercise>

<Exercise title="Back up and tidy" titleAr="النسخ الاحتياطي والترتيب" level="medium">

In one command line: create `~/backup/configs` (with parents), copy `/etc/hosts` and `/etc/hostname` into it with verbose output, then list the directory in long format.

<Ar>في سطر أوامر واحد: أنشئ `~/backup/configs` (مع المجلدات الأب)، وانسخ إليه `/etc/hosts` و `/etc/hostname` مع مخرجات تفصيلية (verbose)، ثم اعرض المجلد بالتنسيق الطويل (long format).</Ar>

<Solution>

```bash
mkdir -p ~/backup/configs && cp -v /etc/hosts /etc/hostname ~/backup/configs && ls -l ~/backup/configs
```

</Solution>

</Exercise>

<Exercise title="Why did rmdir fail?" titleAr="لماذا فشل rmdir؟" level="easy">

`rmdir projects` prints "Directory not empty". What are your options?

<Ar>يطبع `rmdir projects` الرسالة «Directory not empty». ما الخيارات المتاحة لك؟</Ar>

<Solution>

`rmdir` only removes **empty** directories. Either delete the contents first (`rm projects/*`, then `rmdir projects`), or remove everything recursively with `rm -r projects`, after checking with `ls -R projects` that you really want to.

<Ar>`rmdir` يزيل المجلدات **الفارغة** فقط. فإما أن تحذف المحتويات أولًا (`rm projects/*` ثم `rmdir projects`)، أو تزيل كل شيء تعاوديًا (recursively) باستخدام `rm -r projects`، بعد أن تتحقق باستخدام `ls -R projects` من أنك تريد ذلك فعلًا.</Ar>

</Solution>

</Exercise>
